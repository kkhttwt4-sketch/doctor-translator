# دليل بناء وتثبيت تطبيق Doctor Translator على أجهزة Android (APK)

تم تجهيز هذا المشروع بكافة المتطلبات والأيقونات وملفات الإعداد ليعمل كتطبيق أندرويد حقيقي بصيغة APK.

---

## ⚡ الطريقة الأولى: إنشاء ملف APK في دقيقتين (بدون تثبيت برامج)

نظراً لأن المشروع مزود بملف `manifest.json` و `sw.js` وأيقونات مطابقة للمواصفات، يمكنك استخدام أداة **PWABuilder** الرسمية من شركة Microsoft:

1. انشر التطبيق على رابط مجاني (مثل Render أو Vercel).
2. افتح موقع: **[PWABuilder.com](https://www.pwabuilder.com)**.
3. ضع رابط التطبيق واضغط **Start**.
4. سيفحص الموقع المشروع ويعطيك نتيجة فحص كاملة (PWA Ready).
5. اضغط على زر **«Package for Android»**:
   - يمكنك تنزيل ملف **APK جاهز مباشرة** لتثبيته فوراً على أي هاتف Android.
   - أو تنزيل ملف **AAB** إذا كنت تريد رفعه إلى متجر Google Play.

---

## 🛠 الطريقة الثانية: بناء ملف APK محلياً عبر Capacitor و Android Studio

إذا كان لديك برنامج **Android Studio** على جهازك وتريد بناء حزمة APK أصلية:

### الخطوات:
1. فك ضغط ملف المشروع على جهازك وافتح موجه الأوامر (Terminal / Command Prompt) داخل المجلد.
2. قم بتثبيت الحزم المطلوبة:
   ```bash
   npm install
   npm install @capacitor/core @capacitor/cli @capacitor/android
   ```
3. قم ببناء الواجهة ومزامنة منصة الأندرويد:
   ```bash
   npm run build
   npx cap add android
   npx cap sync android
   ```
4. افتح المشروع في Android Studio:
   ```bash
   npx cap open android
   ```
5. داخل Android Studio:
   - اضغط من القائمة العلوية على: **Build > Build Bundle(s) / APK(s) > Build APK(s)**.
   - سيقوم البرنامج بإنشاء ملف: `app-debug.apk` أو `app-release.apk`.
   - انقل هذا الملف إلى هاتفك الأندرويد واضغط عليه لتثبيته فوراً!
